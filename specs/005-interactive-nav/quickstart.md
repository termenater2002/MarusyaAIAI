# Quickstart: Интерактивный навигационный бар

## 1. Кнопка в хедере
- Добавь одну CTA в `siteConfig.header.actions` (href `/navigation`).
- Рендер в `site-header.tsx`, используй `next/link` без перезагрузки.
- Обеспечь hover/focus/active и aria-label.

## 2. Страница `/navigation`
- Серверная страница с секциями: «Гайды», «Обновления», «Обратная связь».
- Семантика: заголовки секций, абзацы/списки, понятные подписи.
- Простая адаптивная сетка (колонки на широких экранах, стек на мобилках).

## 3. Доступность
- CTA фокусируема, работает клавиатурой (Enter/Space).
- Контент страницы читаемый и фокусируемый, достаточно контраста.

## 4. Проверка
- Клик/клавиатура по CTA ведёт на `/navigation` без полной перезагрузки.
- На `/navigation` видны три секции с контентом; таб-навигация проходит через элементы.

---

**Пример импорта меню:**
```ts
import { navigationMenu } from 'src/lib/site-config';
```

**Пример использования:**
```tsx
<NavigationMenu items={navigationMenu.items} />
```
