# Quickstart: Интерактивный навигационный бар

## 1. Создай компонент NavigationMenu
- Используй React/Next.js, Tailwind CSS, shadcn/ui
- Импортируй данные меню из API или статического файла

## 2. Реализуй SPA-навигацию
- Используй next/link для переходов между разделами

## 3. Добавь адаптивность
- На мобильных скрывай пункты меню за бургер-иконкой
- Используй состояние isOpen для управления бургер-меню

## 4. Визуальная обратная связь
- Добавь hover, active, focus состояния для пунктов меню
- Подсвечивай активный раздел

## 5. Проверь доступность
- Tab-навигация, aria-labels, контрастность

## 6. Протестируй на разных устройствах
- Проверь работу меню на десктопе и мобильных

## 7. Следуй Success Criteria из спецификации

---

**Пример импорта меню:**
```ts
import { navigationMenu } from 'src/lib/site-config';
```

**Пример использования:**
```tsx
<NavigationMenu items={navigationMenu.items} />
```
